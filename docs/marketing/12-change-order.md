# ТЗ: приведение продукта к утверждённому курсу SAWAP

Статус: **готовое ТЗ, ждёт разрешения на правки кода** (сейчас действует режим «только .md»).
Документы (docs/marketing) уже приведены к решениям владельца от 2026-10-30.

## Решения владельца (исходные условия)

1. **Единое имя SAWAP** — никаких других склонений и звучаний (Sawa, SawaPApp) нигде.
2. **Уровни рассуждений убираем** — глубину разбора SAWAP определяет сам.
3. **Агентов под разные задачи оставляем** — утверждённая структура.
4. **Пользователи никогда не думают о моделях** — весь опыт от одной сущности SAWAP:
   никаких названий/меток моделей в UI.

### Порядок выката (обязателен)
1. Сервер: принимает отсутствие `reasoning` → авто-глубина (старый клиент ещё шлёт уровни — совместимость).
2. Клиент: убрать UI уровней, перестать слать параметр.
3. Регресс: e2e-мок (`scripts/e2e-mock.js`), smoke (`scripts/smoke-test.cjs`), 3 контрольных хода (простой/соискание/сравнение) — глубина растёт на сложных.
4. Чистка CSS/остатков.

**Критерии приёмки B:** в композере нет пикера уровней; ход выполняется без параметра
`reasoning`; сложные вопросы получают больше шагов, чем простые (замер на 3 кейсах);
консоль без ошибок; старые диалоги открываются.
