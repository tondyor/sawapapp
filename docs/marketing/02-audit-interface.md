## 1. Инвентарь: что реально есть в интерфейсе

### Экраны и поверхности
| Поверхность | Файл | Оценка |
|---|---|---|
| Чат (основной экран) | `src/components/Chat.jsx` | Зрелый, аккуратный |
| Пустое состояние + чипы-подсказки | `Chat.jsx` (блок `empty`) | Хорошая загадка, слабая продажа |
| Шторка выбора агента | `src/components/AgentSheet.jsx` | Чисто, но без «вау» |
| Дровер истории чатов | `src/components/Drawer.jsx` | Утилитарно |
| Живая/сохранённая трасса хода | `src/components/ReasoningTrace.jsx` | **Лучший элемент продукта** |
| Композер: файл + агент + уровень | `Chat.jsx` | Функционально |
| Баннер возобновления хода, «Стоп» | `Chat.jsx`, `App.jsx` | Инженерная зрелость |

### Визуальная система
- Тёмная тема с фоном-звёздным небом (`Background` в `icons.jsx`), glassmorphism-панели.
- Акцент динамический: `--accent` подмешивается под активного агента (5 цветов).
- Шрифт Manrope с Google Fonts (`index.html`).
- Анимации: `rise/fade/slide-up`, пульс точки трассы, typing-dots, scale на кнопках.

### Сильные стороны (что работает на удержание)

1. **Трасса — это визуальное доказательство.** Строка `▶ план · 👁 картинка · 🔎 поиск ·
   📖 страница · 🧠 размышления · ✨ сборка · ✓ ответ` с таймером и меткой модели —
   продукт выглядит «умным» до того, как прочитан ответ. Это самый ценный ассет интерфейса.
2. **Обрыв — не катастрофа.** Возобновление хода, «Ход продолжается…», дренаж событий,
   баннер «Ход не завершён — продолжить?». Пользователь чувствует надёжность.
3. **Уровни усилия (Быстро…Max)** — редкий на рынке контроль глубины. *Решение владельца: убираем — глубину разбора SAWAP определяет сам (см. §7).*
4. **Fork диалога и редактирование сообщения** — продвинутые механики, которых нет у многих.
5. **Markdown-рендеринг с кодом, цитатами, лайтбоксом картинок** — ответы читаются.
6. **Понятные ошибки с «Повторить»** (`errorText` в `api.js`) — редкость для MVP.
7. **Haptic-отклик почти на каждом тапе** — задаток «живого» интерфейса.
8. **Консоль чистая**, e2e-мок существует, aria-labels на иконочных кнопках.

## 2. Критические находки (блокеры роста)

### P0-1. Шрифт с Google Fonts — прямая угроза для целевой аудитории
`index.html:9-10` тянет Manrope с `fonts.googleapis.com`. Для аудитории под санкциями это
блокируемый/замедляемый ресурс: пользователь может получить системный шрифт, задержку рендера
или «пустой» экран до таймаута. **Парадокс: продукт позиционируется как работающий без
заграницы, но сам зависит от Google CDN.**
→ Решение: self-host woff2 (варианты 400/600/700/800), `font-display: swap`, preload.

### P0-2. Нет имени бренда в интерфейсе
В шапке только две иконочные кнопки (`App.jsx:490-499`). Ни логотипа, ни слова SAWAP, ни
статуса «AI-агент». Пользователь попадает в чат без идентичности продукта. Компонент `Logo`
существует в `icons.jsx`, но **нигде не используется**.
→ Решение: шапка = логотип/имя + название агента + индикатор «онлайн/думает».

### P0-3. Нет онбординга и объяснения ценности
Первый экран — агент + 3 чипа. Непонятно: чем это лучше ChatGPT, зачем трасса,
что за агенты, безопасно ли. Конверсия первого открытия → первого хода страдает.
→ Решение: 3-экранное приветствие (или один экран «как это работает») + пояснение
трассы при первом ходе.

### P0-4. Нет продуктовой аналитики
В коде нет ни одного события аналитики (ни install, ни message_sent, ни level_changed).
`turn_events` пишутся, но это отладочные события хода, не воронка. Невозможно мерить
activation/retention, невозможно ставить A/B.
→ Решение: таблица `events` + простой endpoint `track` (см. `09-metrics.md`).

### P0-5. Нет шеринга — убита виральная петля
Лучший контент продукта (красивый ответ с трассой) нельзя вынести наружу. Для Telegram-продукта
это критично: шеринг в чат/канал — главный бесплатный канал роста.
→ Решение: «Поделиться» → картинка-карточка ответа (или текст с префиксом) → отправка в чат.

### P0-6. Нативный `confirm()` при удалении диалога
`App.jsx:389` — системный диалог браузера. В WebView он выглядит дёшево, а на части клиентов
отображается некорректно. Удаление — деструктивное действие без undo.
→ Решение: кастомный bottom-sheet с таймером undo.

### P0-7. Нет favicon, мета-описания, OG-тегов
`index.html` минималистичен до предела: нет `<link rel="icon">`, нет description, нет `theme-color`.
При шеринге ссылки на `app8872967138.tgcloud.ai` — безымянная карточка.
→ Решение: favicon-логотип, `theme-color: #070a12`, description, OG-картинка.

### P0-8. Нет юридической поверхности
Ни политики конфиденциальности, ни оферты, ни дисклеймера «не является юридической
консультацией» на уровне продукта (дисклеймер есть только в промпте Правоведа). Для
работы с персональными данными (152-ФЗ) и доверия пользователей — обязательно.
→ Решение: экран «О приложении / Политика / Оферта» (см. `10-risks.md`).

## 4. Мелкие находки (P2)

- **Тап-таргеты:** кнопки действий у сообщений 30×30 px (`styles.css:169`) — ниже рекомендованных 44 px (иронично: агент-дизайнер сам советует 44 px).
- **`user-scalable=no`** в viewport — ограничивает доступность; проверить, нужен ли он.
- **Нет `prefers-reduced-motion`** — анимации игнорируют системную настройку.
- **Дублирование палитры:** `ACCENTS` захардкожен в `Drawer.jsx:5` и заново в `agents.js` — риск рассинхрона при добавлении агента.
- **Нет `aria-live`** для статуса хода — скринридеры не слышат «Думаю…».
- **Клавиатура:** нет фокус-стилей для внешних клавиатур (десктоп/планшет).
- **Скопировано** — тост живёт 1.2 с, не имеет позиционирования (перекрывает контент).

## 8. Вердикт

Интерфейс — крепкое инженерное MVP с одним выдающимся элементом (трасса) и хорошей
устойчивостью. Ему не хватает **бренда, объяснения ценности, измеримости и виральности** —
ровно того, что превращает «рабочий чат с ИИ» в продукт, который растёт. Все блокеры P0
закрываются за 2–3 спринта без изменения архитектуры.
