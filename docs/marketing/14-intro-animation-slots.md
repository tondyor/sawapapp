# Интро-анимация: слоты контента и правила замены

**Назначение:** обновление текстового и визуального контента интро **без дизайнера
и без редизайна**. Код: `src/components/Intro.jsx`, стили: `src/intro.css`.

Скелет — якорь (имя SAWAP + слоган + факты), лента ВСЕХ агентов, живой
диалог (3 обмена, 3 агента), «нырок» в SAWAP и переход в чат — зафиксирован
ТЗ §4 и меняться не должен. Меняются только значения слотов ниже.

> **Полный редизайн 2026-11-03:** прежняя версия (трасса из 20 действий, HUD,
> инфографика, живой фон, прогресс-бар) удалена полностью по приказу владельца —
> «кадры дергаются на телефонах». Новое интро: только `transform`/`opacity`,
> без фильтров/теней/масок, один rAF-цикл, плоский фон.
>
> **Перевод всей динамики на JS (2026-11-03):** CSS-анимации в интро удалены
> полностью — вход, «нырок», пропуск и прогресс-линия пишутся одним rAF-циклом
> (`applyFrame`) инлайн-стилями. Причина: CSS-анимации не проверяются
> в QA-окружении (headless не продвигает их часы) и хочется детерминированной
> приёмки. `?introAt=<мс>` теперь даёт честный кадр любого момента — теми же
> формулами, что и живой прогон.

> **Решения владельца (2026-11-03):**
> 1. `prefers-reduced-motion` не учитывается — интро всегда играет полную анимацию.
> 2. Аналитика интро **удалена из кода** — события не пишутся.
> 3. CTA нет — замыкание «нырком» в SAWAP и фейдом в чат (4,5–5,0 с).
> 4. Все агенты визуально одинаковые: один чип, одна заливка, одна рамка.
> 5. Лента: первый столбец проходит за **1,5 с** равномерно, остальные плавно
>    ускоряются; финиш ровно на 5,0 с (решение владельца).

## 1. Слоты контента

| Слот | Где в коде | Что можно менять | Правила |
|---|---|---|---|
| **Имя продукта (якорь)** | `.si-word` | — | Только `SAWAP`. Все капсом, разрядка `0.32em`, градиент #ffffff→#aeb6d8 (единственное применение градиента — на тексте, дефолт ТЗ). |
| **Слоган** | `.si-tag` | Текст под именем | Одна строка, без гифенов и восклицательных знаков. Сейчас: «Команда ИИ-агентов в чате». |
| **Факты входа** | `.si-facts` | Текст строки | Только проверяемые факты. Сейчас: «Бесплатно · Без регистрации · Без VPN». При появлении лимита (ТЗ §8) — переписать «Бесплатно». Разделитель `·` — цвет `#5b64f0`. |
| **Агенты (лента)** | `AGENTS` | Состав и порядок 55 имён | ВСЕ 55 агентов проекта (5 активных + 50 «скоро») в порядке реестра, `SAWAP` первым. Подпись чипа = **полное `name`** из `tgcloud/lib/agents.js` (например, «Медицина», а не внутренняя метка «Здоровье»); в `Intro.jsx` — ручной хардкод 55 имён, синхронизировать при изменении реестра. Чипы **одинаковые** — без бейджей, без разной заливки. |
| **Диалог (6 сообщений)** | `DIALOG` | Тексты, порядок, агенты | 3 обмена: пользователь → **Маркетолог** (стратегия упаковки услуги), `@Копирайтер` → **Копирайтер** (заголовок для лендинга), `@Правовед` → **Правовед** (риски договора, ст. 16 ЗоЗПП). Каждое сообщение печатается по словам, следующее — после предыдущего (0,3–4,3 с). Пример честный: только активные агенты и применимые советы. |
| **Подсказка пропуска** | `.si-hint` | Текст | «нажми, чтобы пропустить». |

## 2. Вариативность

Порядок агентов фиксированный. Ни перемешивания, ни seed — детерминированный
проход при каждом открытии.

## 3. Тайминги (править только осознанно)

Константа `T` и функции `applyFrame`/`ribbonState` в `Intro.jsx` — единственный
источник движения (CSS-анимаций в интро нет):

- Вход: имя 0.12–0.68 с (подъём + fade), слоган 0.28–0.84 с, факты 0.42–0.84 с,
  чат 0.2–0.6 с, подсказка 1.1–1.52 с.
- Лента (`ribbonState`, rAF): 5 рядов × 11 столбцов, первый столбец (5 активных)
  проходит за **1,5 с** равномерно; 1,5–5,0 с — остальные с плавным ускорением
  (smoothstep, монотонно, стык без обрыва), последний чип уходит за левый край
  ровно на 5,0 с. Скорость фазы 2 выведена из точного пути — `vE` считается
  автоматически.
- Диалог: сообщения печатаются друг за другом 0,3–4,3 с (см. `DIALOG`:
  `delay` + `duration` у каждого); все шесть успевают полностью напечататься
  до «нырка»; чат автоматически прокручивается к новому сообщению.
- «Нырок»: 4,5–5,0 с — слово раздувается (scale 1→26) и растворяется, вспышка-ядро
  (пик ~4,7 с) гаснет к 5,0 с, корень растворяется по smoothstep; в 4,5 с под
  интро собирается новый чат (агент SAWAP). Переход — **ровно 0,5 с**.
- Пропуск — **тап по любому месту экрана**, фейд 180 мс без «нырка» (ведёт в тот
  же новый чат). Жёсткий потолок — **5 секунд**. Движение — только `transform`/`opacity`.

## 4. Debug-параметры (для QA, в проде не используются)

| Параметр | Действие |
|---|---|
| `?introAt=2500` | Замороженный кадр на 2,5 с: те же формулы `applyFrame`, что в живом прогоне. `?introAt=4650` — середина «нырка». Тап в этом режиме сразу завершает интро. |

Замороженный кадр применяется синхронно при монтировании (`applyFrame(frozen)`)
и повторно после загрузки шрифтов — годится для скриншот-приёмки любого момента.

## 5. Источники и палитра

- Фон — `--bg #070a12`; текст `--text #edf0fa`; приглушённый `--muted #98a1b8`;
  чипы `#141a26` + рамка `--border`.
- Шрифт Manrope (подключён в `index.html`).
- Отсутствующие в новом дизайне сущности (трасса, HUD, прогресс-бар, фон SVG,
  свечение, `AgentIcon`, `Background`) больше не используются интро — не возвращать
  без прямого приказа владельца.
- Классы интро именуются с префиксом `si-` / `intro-si` — не пересекаются
  с глобальными (`styles.css`) и прежними `in-*`.
- CSS-анимации в интро не добавлять: вся динамика в JS — ради проверяемости
  (`?introAt=`) и детерминированности. `intro.css` — только раскладка и цвета.
