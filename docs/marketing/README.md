# SAWAP — маркетинговый пакет

Полный аудит интерфейса MVP + стратегия выхода на российскую аудиторию.
Документы подготовлены по состоянию кода от 2026-10-29 (реальная сборка, живой прогон в моке).

## TL;DR

**Что есть:** рабочий AI-агент в Telegram (бот @sawapapp + Mini App), 5 ролей, агентские ходы
с планировщиком, живой трассой размышлений, поиском, vision и файлами. Инженерно это сильно:
ход переживает обрывы, трасса прозрачна, ошибки изолируются.

**Главная проблема:** продукт не выглядит и не ведёт себя как бренд. Нет имени в интерфейсе,
нет онбординга, нет аналитики, нет шеринга, нет юр. документов. Его достоинства не видны
пользователю за 10 секунд.

**Главный актив для маркетинга:** трасса «как агент думает» — это визуально цепляет и
превращает ответ в доказательство. Всё остальное должен вытащить на поверхность интерфейс.

**Стратегия:** один агент вместо линейки моделей — весь арсенал нейросетей NVIDIA под капотом
через харнесс оркестрации (контекст, память, роли внутри одного хода). Доступ из РФ без VPN
и карты, прозрачность вместо «чёрного ящика», полностью бесплатно для пользователей —
финансирует инвестор за реально активных пользователей. Telegram как дистрибуция и виральная петля.

**Решения владельца (2026-10-30):** единое имя **SAWAP** — никаких других написаний;
уровни рассуждений убираются — глубину разбора SAWAP определяет сам; агентов под задачи
оставляем; модели полностью невидимы пользователю — весь опыт от одной сущности SAWAP.

## Порядок работы

1. Прочитать `02-audit-interface.md` и закрыть блокеры P0 (шрифт, аналитика, онбординг, бренд).
2. Утвердить `03-brand.md` и `08-messaging.md` — они нужны всем следующим шагам.
3. Реализовать «живой интерфейс» из `07-interface-vision.md` и харнесс из `11-harness-vision.md` — продуктовое отличие и фундамент универсальной ценности.
4. Запустить воронку и первые посевы по `06-strategy.md`, мерить по `09-metrics.md`.
5. До масштабирования посевов — юридический чек-лист из `10-risks.md`.
