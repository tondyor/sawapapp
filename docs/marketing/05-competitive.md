# Конкурентный ландшафт и позиционирование SAWAP

Срез по российскому рынку AI-ассистентов (2026). Цель — найти позицию, где SAWAP
невоспроизводим простым «ещё одним чат-ботом».

## 2. Ключевые инсайты

1. **Прозрачность — свободная ниша.** Ни один крупный игрок в РФ не показывает, как именно
   агент пришёл к ответу (шаги, источники, время). SAWAP уже это делает — трасса есть в коде.
2. **«Агент с планом» — тоже свободная ниша.** Массовые ассистенты отвечают одним проходом.
   SAWAP планирует, читает страницы, пере-планирует — это другой класс продукта (агент, а не чат).
3. **Telegram как дистрибуция недооценён.** У конкурентов из РФ — приложение/сайт. У SAWAP
   точка входа там, где человек уже живёт: без установки, без регистрации, без карты.
4. **Слабость SAWAP — знакомство с именем.** «Яндекс/GigaChat» — это доверие. SAWAP придётся
   зарабатывать доверие прозрачностью и кейсами, а не брендом.

## 3. SWOT

**Сильные стороны**
- Агентный ход: план → шаги → re-plan → синтез; устойчив к обрывам; возобновляем.
- Живая трасса с источниками — визуальное доказательство ума.
- Один агент, разные роли — вместо линейки моделей (дешевле в поддержке, понятнее пользователю).
- Глубину разбора SAWAP определяет сам — пользователь не касается технических настроек.
- Доступ из РФ из коробки: Telegram + полная бесплатность для пользователей + данные в БД Telegram.
- Vision (фото/скриншоты/документы) и поиск с ридером — широкий круг задач.

**Слабые стороны**
- Нет бренда, онбординга, аналитики, шеринга (см. аудит) — продукт невидим.
- Нет юр. поверхности (оферта, политика) — барьер для роста и работы с данными.
- Зависимость от NVIDIA API и Telegram Serverless (молодая платформа, CLI 0.2.0 с багами).
- Нет генерации изображений/видео — у конкурентов это «вау».
- Один разработчик/команда — скорость выпуска фич ограничена.

**Возможности**
- Слой «отрезанных от ChatGPT» растёт быстрее, чем догоняют отечественные ассистенты.
- Telegram-экосистема даёт дистрибуцию и виральность без App Store/Google Play.
- Рынок «агентов» только зарождается — SAWAP уже имеет агентную архитектуру.
- B2B-сегмент (малый бизнес) массово не обслужен отечественными игроками.
- Можно отстроиться на «безопасности данных»: диалоги в облаке Telegram, ключи не у третьих лиц.

**Угрозы**
- Яндекс/Сбер могут добавить «показ мыслей» и агентные роли быстро — у них дистрибуция.
- Санкционное давление может ударить по доступу к NVIDIA API для РФ-пользователей (см. риски).
- «Зеркала ChatGPT» дешевле и брендированнее.
- Изменения правил Telegram Serverless / стоимости LLM.

## 4. Позиционирование

### Утверждение позиции
> Для людей и фрилансеров в России, которым нужен по-настоящему умный помощник, но без VPN,
> заграничных карт и «чёрного ящика» — **SAWAP**: AI-агент внутри Telegram, который строит
> план, читает источники и **показывает, как думает**, отвечая по-русски.

### Формула дифференциации
**Категория:** агент-помощник (не чат-бот, не поисковик).
**Лучшая альтернатива:** «ChatGPT через зеркало или Алиса».
**Ключевое отличие:** план + шаги + прозрачная трасса + доступ из РФ.
**Доказательство:** трасса с источниками на экране, устойчивость к обрывам, реальные кейсы.

### Позиционная карта (оси)
- X: **Закрытый «чёрный ящик» ←→ Открытый «показываю ход мысли»**
- Y: **Простой чат-ответ ←→ Агент с планом и инструментами**

```
                Агент с планом
                       ▲
        SAWAP ●        │   (будущее: агенты с MCP/инструментами)
                       │
 Простой чат ◄─────────┴────────────► Показываю ход
        Алиса, GigaChat                ChatGPT (частично)
```
SAWAP занимает верхне-левый квадрант почти один.

## 5. Позиционирование по отношению к конкретным конкурентам (для текстов)

- **против «ChatGPT через зеркала»:** «Без VPN, без чужих карт и без риска забана. Работает там же, где ты общаешься — в Telegram.»
- **против «Алиса/GigaChat»:** «Это не диктовка и не поиск по Яндексу. Агент строит план, читает страницы и показывает, откуда взял ответ.»
- **против «просто спросить в чате»:** «Ответ с доказательством: шаги, источники, ссылки. И не теряется, если связь моргнула.»
- **против «дорогие зарубежные подписки»:** «Один агент со всеми навыками — бесплатно. Без VPN, зеркал и подписок.»

## 6. Чего SAWAP не должен делать

- Не гнаться за генерацией картинок/видео на MVP (это узкие конкуренты, другой чек).
- Не обещать «лучше ChatGPT по всему» — выигрывать на прозрачности, доступности и агентности.
- Не скрывать зависимость от NVIDIA — честность о технологиях усиливает доверие.
- Не позиционировать как «для программистов» — массовый сегмент важнее.
