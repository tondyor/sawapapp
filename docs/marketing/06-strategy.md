# Маркетинговая стратегия SAWAP

Цель документа: как из рабочего MVP получить растущую активную аудиторию, **не беря денег
с пользователей**. Финансирует инвестор — за реально активных пользователей.

---

## 1. Модель финансирования и главная цель

- Пользователи не платят никогда: нет подписок, пакетов, paywall и «промо-лимитов как ловушек».
- Инвесторы оплачивают рост **реально активной** аудитории.
- **Северная звезда:** WAU — пользователи, сделавшие ≥ 3 завершённых ходов за неделю.
- **Экономический показатель:** стоимость активного пользователя (инфра: LLM-шаги, хостинг,
  поиск) должна оставаться ниже инвестиционной ставки на активного пользователя.
- **Честность метрик:** определение «реально активного» открыто и зафиксировано
  (завершённый ход с синтезом от уникального пользователя), анти-фрод включён. Накрутка = смерть модели.

Следствие для маркетинга: весь рост работает на два показателя — **привлечь** и **удержать
пользой**. Никаких механик «выдавливания денег».

## 2. Уникальное торговое предложение

**Одно предложение:**
> Один AI-агент в Telegram, который решает любые задачи как специалист: строит план,
> читает источники и показывает, как думает. Весь арсенал моделей NVIDIA под капотом.
> Полностью бесплатно.

**Расширение (для лендинга):**
> SAWAP объединяет нейросети NVIDIA в одного ассистента с ролями: юрист, маркетолог,
> копирайтер, дизайнер, собеседник. Сложный вопрос он разбирает по шагам — с поиском,
> чтением страниц и прозрачной трассой рассуждений. Работает в Telegram: открыл — спросил —
> получил. Без VPN, по-русски, бесплатно.

**Почему это выигрывает:**
1. Доступ из РФ — снимает главный барьер.
2. Прозрачность — снимает главный страх («врёт/выдумывает»).
3. Агент с планом — снимает главное разочарование («просто отвечает, не делает»).
4. Один агент на все задачи — снимает нагрузку выбора («какую модель/сервис открыть»).
5. Бесплатно — снимает последний барьер.

## 3. Стратегические столпы

1. **Показывать, как думает (прозрачность).** Трасса — витрина, маркетинг живёт кейсами
   «вот план, вот шаги, вот ответ со ссылками».
2. **Быть там, где живёт аудитория (Telegram).** Ноль трения: ссылка → бот → чат.
3. **Один агент — весь арсенал моделей (харнесс).** Пользователь выбирает задачу и глубину,
   а не модель. Харнесс сам подбирает модель под каждый шаг хода
   ([11-harness-vision.md](11-harness-vision.md)).
4. **Универсальная ценность на каждый день.** Продукт отвечает не «на запрос про ИИ», а на
   любую потребность: утренний бриф, документ, письмо, разбор скрина, обучение, планирование.
5. **Память и персонализация — причина остаться.** Каждый следующий ответ учитывает,
   кто ты и что делал раньше ([11-harness-vision.md](11-harness-vision.md), §память).
6. **Доверие через честность.** Ограничения, технологии, лимиты — открыто; без dark patterns.

## 4. Фазы

### Фаза 0 — «Продукт готов к гостям» (2–3 недели, см. [02-audit-interface.md](02-audit-interface.md) P0)
Шрифт, бренд в шапке, онбординг, аналитика, шеринг, favicon/мета, юр. экраны.
Без этого посевы сливать нельзя.

### Фаза 1 — «Люди и кейсы» (месяц 1–2)
- Собственный Telegram-канал SAWAP: 3 кейса в неделю (запрос → трасса → ответ).
- 10–20 посевов в профильных каналах (фриланс/маркетинг/юр/студенты).
- 50 активных тестеров с фидбек-каналом.
- Метрики: конверсия открытие → первый ход ≥ 60%, D7 ≥ 25%.

### Фаза 2 — «Виральность» (месяц 2–4)
- Шеринг ответов из продукта (кнопка + карточка).
- Рефералка «пригласи друга — пользуйтесь вместе» + ранний доступ к новым сценариям.
- Серия коротких видео (трасса в действии) для Shorts/Reels/YouTube.
- Метрика: вирусный коэффициент ≥ 0.3, 30% новых — из шеринга/рефералки.

### Фаза 3 — «Привычка и удержание» (месяц 3–6)
- Память пользователя (профиль + эпизоды) — ответы становятся персональными.
- Ежедневные сценарии: утренний бриф, план дня, рабочие задачи.
- Follow-up по незакрытым задачам (строго по согласию).
- Метрики: D30 ≥ 20%, сценариев на активного ≥ 3.

### Фаза 4 — «Универсальность и масштаб» (месяц 6–12)
- Расширение каталога сценариев харнесса (новые типы шагов и моделей).
- Новые агенты по данным реальных запросов.
- Командные аккаунты (общая память команды).
- Локализация (английский — вторым).

## 6. Воронка

```
Контент / посев / шеринг
      ↓  (крючок: «посмотри, как агент думает»)
Бот @sawapapp /start → приветствие + кнопка «Открыть приложение»
      ↓
Mini App: онбординг (3 экрана) → пустое состояние с чипами подсказок
      ↓
Первый ход → трасса вживую → вау-момент (источники/шаги)
      ↓
Повторный ход в тот же день → сохранение диалога (привычка)
      ↓
Память и персонализация → агент «узнаёт» пользователя → возврат сам собой
      ↓
Follow-up / утренний бриф (по согласию) → ежедневная привычка
      ↓
Шеринг ответа / приглашение друга → новый пользователь в воронке
```

Ключевые точки конверсии:
- открытие → первый ход: онбординг + чипы-подсказки + крючок трассы.
- первый ход → второй: умные заголовки диалогов + «продолжить с этого места» (fork есть).
- второй ход → неделя: память + каталог сценариев.
- неделя → месяц: follow-up + бриф + широта пользы.

## 7. Контент-стратегия (что публиковать)

1. **Кейсы с трассой:** «Спросил Правоведа про возврат товара — вот план и источники».
2. **Сравнения:** «Один вопрос — ChatGPT (через VPN) и SAWAP: разница в подходе».
3. **«Один вопрос — один агент»:** демонстрация переключения ролей.
4. **Образовательный:** «Как формулировать запрос, чтобы получить разбор по шагам».
5. **Короткие видео:** 15 секунд — вопрос → бегущая трасса → ответ.
6. **«Польза на каждый день»:** серия «5 минут с SAWAP» — бриф, письмо, разбор, план.

Правило: **не продаём «ИИ», показываем решённую задачу** (договор, пост, план, разбор скрина).

## 8. Движок удержания (вместо монетизации)

Раз продукт бесплатен, единственная валюта — возвращение пользователя. Что удерживает:

| Механика | Что даёт пользователю | Метрика возврата |
|---|---|---|
| Память профиля (L2) | Ответы сразу «в твоём контексте», без пересказа себя | Доля ходов с использованием памяти |
| Эпизодическая память (L1) | «Продолжим с того места» в любой день | Возвраты в тот же диалог |
| Follow-up | «Вчера разбирали договор — дедлайн в пятницу, продолжим?» | CTR follow-up |
| Утренний бриф (opt-in) | 2-минутная сводка по твоим темам | DAU-прирост от брифа |
| Каталог сценариев | Любая новая потребность — тот же вход | Широта пользы (сценариев/пользователя) |
| Telegram-native | Уведомления там, где человек живёт | Открываемость, отписки |

Правила удержания (без dark patterns — это и брендовое правило, и защита инвесторской метрики):
- Уведомления только по явному согласию, ограниченная частота, отписка в один тап.
- Никаких искусственных «streak-ловушек», страха пропуска и манипулятивных таймеров.
- Польза важнее сессии: короткий полезный ход лучше долгого пустого.
- Память прозрачна: пользователь видит, что SAWAP помнит, и может удалить всё.

## 9. Экономика (инвесторская)

| Показатель | Определение | Цель |
|---|---|---|
| CAU (cost per active user) | Инфра-затраты на активного пользователя в месяц | Ниже инвестиционной ставки |
| Доля дешёвых шагов | Шаги на лёгких моделях от всех шагов | ≥ 70% без падения качества |
| Кэш-попадания | Повторные чтения из кэша (vision, страницы) | Растёт |
| Стоимость хода | Средняя по глубине хода (авто) | Снижается при том же качестве |

Рычаги CAU — не «отобрать у пользователя», а харнесс: маршрутизация шагов на дешёвые модели,
кэш, бюджеты шагов ([11-harness-vision.md](11-harness-vision.md), §экономика).
