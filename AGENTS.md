## КРИТИЧЕСКОЕ ПРАВИЛО №1 — коммит и push любого прод-изменения

**Любое изменение, попадающее в Telegram-продакшн, обязано сразу коммититься и пушиться в GitHub-репозиторий `tondyor/sawapapp`.**

- Продакшн = всё, что деплоится на платформу Telegram: `npx tgcloud push` (модули `tgcloud/` + сборка Mini App), `npx tgcloud migrate` (изменения схемы БД), правки фронтенда, уходящие в прод.
- Порядок работы без исключений: изменение → деплой/миграция в прод → `git add` → `git commit` → `git push` в `origin/main`. Промежуток между деплоем в прод и push'ем в GitHub минимален.
- Нельзя оставлять прод-изменения только в рабочей папке или только в облаке: состояние без коммита в GitHub считается потерянным (история проекта — единственный источник истины о том, что и когда менялось).
- Исключений нет. Если push невозможен (нет сети, ошибка git) — изменение не считается завершённым: сообщить пользователю в чат и довести push до успеха.
